Research Themes
🛡️

Network Security & Vulnerability

Intrusion detection, traffic forensics, and automated vulnerability discovery, including fuzzing and zero-day hunting across networks and agents.

IDS Fuzzing Zero-day
🔭

System Observability

eBPF-based full-stack instrumentation to continuously monitor networked systems with minimal overhead, enabling kernel-to-application tracing in production.

eBPF Tracing Low Overhead

Agent Security

Runtime security, resource abuse detection, and dependability analysis for LLM-based autonomous agents, bridging OS-level enforcement and agent reasoning.
