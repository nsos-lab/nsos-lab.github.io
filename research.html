Research at NSOS

Problem-driven and interest-led: we start from questions that matter in networked-systems observability and AI-agent security, then build the measurements, systems, and evidence to answer them.

Our Approach

Questions first, tools second

We choose research problems the way practitioners feel them — a system that cannot be observed, an agent that cannot be trusted — and let genuine interest carry the work across layer boundaries.

❓

Problem-driven

🧭

Interest-led

🌉

Across layers

We work from kernel to network to agent reasoning, because security and observability problems rarely respect layer boundaries.

Open Problems

Problems we are solving right now

Two questions currently drive most of our effort. Each is stated the way we ask it in the lab.

Q1

How severe is the Agent DoS caused by indirect prompt injection, really?

Indirect Prompt Injection Agent DoS Black-box Detection Large-scale Measurement

Why it matters

LLM agents browse and act on the open web autonomously. Indirect prompt injection lets an ordinary-looking page plant instructions that hijack an agent's control flow — for example, trapping it in execution loops that burn its step, time, and token budgets. This is denial of service at the agent layer: real cost in tokens and compute, tasks that silently fail, and so far no systematic measurement of how bad it can get.

Q2

Can eBPF genuinely improve the security and observability of AI agents?

eBPF Agent Observability Runtime Enforcement Kernel-level Telemetry

Why it matters

Today's agent guardrails live in the same layer the attacker manipulates — prompts, framework hooks, application logic. But an agent that reasons its way past application-level checks still cannot hide its syscalls, file accesses, and network egress. Kernel-level visibility through eBPF is tamper-resistant, low-overhead, and agent-agnostic — a fundamentally different place to observe and to enforce.

Research Themes

Themes behind the questions

Our open questions grow out of three long-term themes. Q1 lives in agentic AI safety; Q2 is where system observability meets agent safety.

🔭

System Observability

eBPF-based full-stack instrumentation to continuously monitor networked systems with minimal overhead — kernel-to-application tracing in production.

🤖

Agentic AI Safety

Runtime security, resource-abuse detection, and dependability analysis for LLM-based autonomous agents — bridging OS-level enforcement and agent reasoning.

🛡️

Network Security

Intrusion detection, traffic forensics, and automated vulnerability discovery — fuzzing and zero-day hunting across networks and agents.
